# Family Trip app

Phone app (PWA) for our family trip to Egypt: plan and day briefs, places and photos, ideas with votes, and shared expenses with bills.

- `index.html`, `app.js`, `styles.css`: the app (no build step). Hosted with GitHub Pages.
- `config.js`: the Supabase project URL and publishable key (safe to be public).
- `supabase/schema.sql`: the database. Run it in Supabase → SQL Editor; safe to re-run after updates.
- `SETUP.md`: setup notes.
